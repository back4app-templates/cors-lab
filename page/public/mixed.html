Mixed content (https page → http API) — look-alike fixture

Open this page on the https origin (https://localhost:1349, after npm run cert). The default target http://127.0.0.1:1345/ok has this https origin in its CORS allowlist, so the one changed factor is the TARGET'S scheme. Note: browsers treat loopback addresses as potentially trustworthy, so an http loopback target may NOT trigger mixed-content blocking — whatever happens is the capture; to force a non-loopback cell, put this machine's LAN IP in the box (e.g. http://192.168.x.y:1345/ok — that origin must then be added to ALLOWED_ORIGINS, and the API reached via the LAN name, which stays on this machine).
