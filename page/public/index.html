cors-lab — one button per failure

Each button fires one labeled fetch with a fresh correlation id (cid, a query param — never a header, so it cannot change the request's CORS classification), prints exactly what fetch saw, then asks the API's /__state what the server logged for that cid. "The preflight blocked it (no main request executed)" and "it ran and the browser hid the answer" are different outcomes and are reported separately. Other fixtures: timing series · Local Network Access · mixed content.
